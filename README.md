# MAI / mobile-web — лабораторные работы

Репозиторий для лабораторных работ по дисциплине «мобильная веб-разработка» (МАИ).
Каждая работа лежит в **отдельной папке** с префиксом `labNN-`, чтобы работы не смешивались:

| Папка | Работа | Статус |
|---|---|---|
| [`lab01-stat-server/`](lab01-stat-server/README.md) | Лабораторная работа №1, **вариант №7** — сервер статистики аналитики сайта | готова |
| `lab02-…/` | следующая работа | появится позже |

Правило: внутри папки лаборатории — свои `package.json`, код, тесты и документация;
общих зависимостей между работами нет.

## Лабораторная работа №1 (вариант 7) — кратко

Сервер на Node.js (без внешних зависимостей) собирает статистику посещений, которую асинхронно
отправляет браузер, и показывает её в виде графиков: просмотры страниц, уникальные посетители,
сессии и их длительность, устройства (включая Аврора), источники переходов, экспорт CSV.

```bash
cd lab01-stat-server
npm start          # http://localhost:3000/  + адрес для телефона в локальной сети
npm run seed       # демо-данные для графиков
npm test           # 33 проверки API
npm run test:ui    # 16 проверок интерфейса (нужен npm install)
```

Подробное описание, API, метрики, запуск и сценарий демонстрации — в
[`lab01-stat-server/README.md`](lab01-stat-server/README.md) и [`lab01-stat-server/docs/`](lab01-stat-server/docs/README.md).
