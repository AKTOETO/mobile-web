# MAI / mobile-web — лабораторные работы

Репозиторий для лабораторных работ по дисциплине «мобильная веб-разработка» (МАИ).
Каждая работа лежит в **отдельной папке** `labNN/`, внутри — сервер и клиентские
приложения:

| Папка | Работа | Статус |
|---|---|---|
| [`lab01/stat-server/`](lab01/stat-server/README.md) | Лабораторная работа №1, **вариант №7** — сервер статистики аналитики сайта (Node.js) | готова |
| `lab01/aurora-app/` | Приложение под **ОС Аврора** (Qt/QML), клиент статистики по WebSocket | код готов, требует сборки в SDK |
| `lab02/…` | следующая работа | появится позже |

Правило: внутри папки лаборатории — свои `package.json`/`rpm`, код, тесты и
документация; общих зависимостей между работами нет.

## Лабораторная работа №1 (вариант 7) — кратко

Сервер на Node.js (без внешних зависимостей) собирает статистику посещений,
которую асинхронно отправляет браузер, и показывает её в виде графиков: просмотры
страниц, уникальные посетители, сессии и их длительность, устройства (включая
Аврора), источники переходов, экспорт CSV. Дополнительно сервер отдаёт
**WebSocket-канал `/ws`**, к которому подключается приложение под ОС Аврора.

### Сервер (`lab01/stat-server`)

```bash
cd lab01/stat-server
npm start          # http://localhost:3000/  + адрес для телефона в локальной сети
npm run seed       # демо-данные для графиков
npm test           # 33 проверки API
npm run test:ws    # 9 проверок WebSocket-канала /ws
npm run test:ui    # 16 проверок интерфейса (нужен npm install)
```

### Приложение под Аврору (`lab01/aurora-app`)

```bash
export PATH="$HOME/AuroraOS/bin:$PATH"
cd lab01/aurora-app
sfdk config target=AuroraOS-5.1.1.60-base-x86_64
sfdk build
sfdk deploy --pkcon
```

Описание сервера, API, метрик и сценария демонстрации — в
[`lab01/stat-server/README.md`](lab01/stat-server/README.md) и
