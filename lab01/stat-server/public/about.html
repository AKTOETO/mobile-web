О проекте

Лабораторная работа №1 «Взаимодействие с web-клиентом», вариант 7 — сервер статистики аналитики сайта.

Какие показатели считаются

ПоказательКак считается
Просмотры страницчисло событий pageview (по одному на каждое открытие страницы)
Уникальные посетителичисло различных visitorId; идентификатор хранится в localStorage браузера
Сессияцепочка событий одного посетителя без перерыва дольше 30 минут
Длительность сессиипоследнее событие − первое событие, продлевается heartbeat-запросами, закрывается по session_end или таймауту
Глубина просмотрасреднее число просмотров за сессию
Показатель отказовдоля сессий ровно с одним просмотром
Устройстваклассификация по User-Agent: desktop / mobile / tablet / aurora
Источники переходовпереходы напрямую, изнутри сайта и с внешних сайтов (по document.referrer)

Требования задания и где они выполнены

ТребованиеРеализация
Серверное ПО на любом языкеNode.js, только встроенные модули (http, fs, path, crypto)
Web-интерфейс в браузереpublic/index.html, catalog.html, contact.html, about.html, dashboard.html
JS управляет действиями пользователя и кнопками формыpublic/js/app.js (фильтр каталога, форма обратной связи), public/js/dashboard.js (форма отчёта)
Асинхронный вызов в JSasync/await, Promise.all, fetch, AbortController в api.js, tracker.js, dashboard.js
Адаптивная вёрстка через @mediapublic/css/style.css и public/css/dashboard.css (992 px, 768 px, 480 px)
Работа в локальной сетисервер слушает 0.0.0.0:3000 и печатает адрес для телефона
Визуализация результатаграфики на <canvas> в public/js/charts.js: столбцы, временная линия, кольцевая диаграмма
