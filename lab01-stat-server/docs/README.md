## Кратко о решении

- **Сервер:** `server/server.js` — HTTP-сервер на встроенных модулях Node.js (`http`, `fs`, `path`, `crypto`).
  Никаких внешних библиотек: работает офлайн, достаточно `node server/server.js`.
- **Хранение:** один JSON-файл `data/stats.json` (посетители, сессии, события, сообщения формы).
  Запись пачками и атомарно (tmp-файл + `rename`).
- **Клиент:** `public/js/tracker.js` подключается на каждой странице сайта и асинхронно
  (`fetch`, `async/await`, `sendBeacon`) отправляет `pageview`, `action`, `heartbeat`, `session_end`.
- **Визуализация:** `public/js/charts.js` рисует 4 графика на `<canvas>` без библиотек.
- **Формы и кнопки:** `public/js/app.js` (фильтр каталога, форма обратной связи) и
  `public/js/dashboard.js` (форма отчёта: период, страница, автообновление, экспорт CSV, сброс).
- **Адаптивность:** `public/css/style.css`, `public/css/dashboard.css` — `@media` на 992 px, 768 px, 480 px,
  плюс тёмная тема и правила печати.
