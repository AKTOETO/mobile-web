# 1. Постановка задания и соответствие требованиям

## Текст задания (лабораторная работа №1)

> Необходимо разработать серверное программное обеспечение на любом языке программирования,
> реализующее логику работы в соответствии с вариантом. Данное серверное обеспечение должно
> взаимодействовать с пользователем посредством браузера, иметь web-интерфейс. Для реализации
> web-интерфейса необходимо создать файлы html, css и js. Файлы js должны обеспечивать функции
> управления пользовательскими действиями, обрабатывать нажатия на кнопки web-формы. Кроме того,
> необходимо добавить асинхронный вызов js (async, promise и т.д.). В css файле обеспечить адаптивную
> вёрстку под различные разрешения экрана с использованием @media.
> Реализованное программное обеспечение запускается в локальной сети. Демонстрируется работа
> приложения в браузере десктопной ОС (ПК) и в браузере мобильного телефона под управлением ОС Аврора.

**Вариант №7:** Сервер статистики аналитики сайта. Простое решение для сбора статистической
информации о посетителях сайта: количество просмотров страниц, уникальные посетители, длительность
сессий. Данные собираются асинхронно через JS и сохраняются на сервере с визуализацией результатов
в виде графиков или диаграмм.

## Что именно считается «аналитикой» по варианту 7

1. **Количество просмотров страниц** — сумма событий `pageview` (за период и за всё время).
2. **Уникальные посетители** — количество различных `visitorId` (новый/вернувшийся отдельно).
3. **Длительность сессий** — среднее, максимум и длительность каждой последней сессии;
   сессия продлевается heartbeat-запросами и закрывается по `session_end` или таймауту.

Дополнительно (для полноты отчёта): глубина просмотра, показатель отказов, устройства,
источники переходов, количество нажатий кнопок, экспорт CSV.

## Критерий «простое решение»

Решение сознательно сделано без фреймворков и БД: один HTTP-сервер, один JSON-файл,
обычный `canvas` для графиков. Это упрощает запуск на любом ПК (даже без интернета)
и объяснение кода на защите.
