Как собираются данные

  1. При открытии страницы tracker.js отправляет событие pageview.
  2. Клиент хранит идентификатор посетителя в localStorage, а сессию — в sessionStorage.
  3. Пока страница открыта, каждые 30 секунд отправляется heartbeat — он продлевает сессию.
  4. Клик по кнопке с атрибутом data-track создаёт событие action.
  5. При закрытии вкладки отправляется session_end — сервер фиксирует длительность сессии.
